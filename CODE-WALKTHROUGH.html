KIẾN THỨC CƠ BẢN

REACT HOẠT ĐỘNG NHƯ THẾ NÀO?

Component là một phần giao diện có thể đặt tên và tái sử dụng. Trong dự án, SiteHeader là thanh điều hướng, HeroSection là ảnh bìa, SpeciesSection hiển thị loài cá, còn SiteFooter là chân trang.

frontend/src/App.jsx đặt các component cạnh nhau để tạo trang. Ví dụ:

<SiteHeader /> <HeroSection /> <SpeciesSection fish={visibleFish} />

Tên component viết hoa để React nhận ra đây là component. Các component nhỏ giúp người học tìm đúng phần cần sửa, thay vì đọc một tệp chứa cả website.

Props là dữ liệu hoặc hàm component cha gửi cho component con. Ví dụ, <SpeciesSection fish={visibleFish} onSelectFish={openFish} /> gửi danh sách cá và hàm mở hồ sơ xuống component con.

useState lưu trạng thái có thể thay đổi khi người dùng thao tác. App.jsx lưu từ khóa tìm kiếm, nhóm cá và độ khó đã chọn. FishCard lưu trạng thái yêu thích của riêng thẻ đó. Khi state thay đổi, React tự cập nhật phần giao diện liên quan.

Dashboard dùng state để điền biểu mẫu và cập nhật danh sách cá. App.jsx là nơi giữ danh sách chung để danh mục ngoài trang chủ cập nhật ngay sau khi admin lưu.

App.jsx dùng filter() trực tiếp để tính danh sách cá đang khớp với bộ lọc. Với danh sách mẫu nhỏ, cách viết thẳng giúp code dễ đọc; chỉ nên thêm useMemo khi việc tính toán thật sự nặng hoặc đã đo thấy ảnh hưởng hiệu năng.

map() lặp qua mảng và tạo một phần tử giao diện cho mỗi dữ liệu. Ví dụ, fish.map(...) tạo một FishCard cho mỗi loài. Thuộc tính key={item.id} giúp React nhận diện ổn định từng thẻ khi danh sách thay đổi.

MATERIAL UI (MUI)

MUI là thư viện component giao diện cho React. Dự án dùng Button cho nút, Select/MenuItem cho lựa chọn, Card cho thẻ cá, Chip cho nhãn độ khó, TextField cho ô email và IconButton cho nút menu/yêu thích.

frontend/src/theme.js tạo theme chung. Theme đặt màu chính, màu nhấn, font, góc vuông và kiểu mặc định cho nút. Khi muốn đổi màu hoặc cách hiển thị mặc định của MUI, bắt đầu từ tệp này. frontend/src/styles.css tinh chỉnh để các component MUI khớp thiết kế riêng của website.

DỮ LIỆU, BỘ LỌC VÀ HỒ SƠ CÁ

frontend/src/data/fish.js xuất một mảng các loài cá nước ngọt. Mỗi loài có id, tên thường gọi, tên khoa học, nhóm cá, mức chăm sóc, thông số, ảnh và liên kết nguồn. Tách dữ liệu khỏi giao diện giúp thêm cá mà không phải viết lại component.

Trong App.jsx, filter() tìm theo tên thường gọi hoặc tên khoa học rồi áp dụng bộ lọc nhóm cá và độ khó. filter() không sửa mảng gốc; nó tạo danh sách kết quả mới và truyền xuống SpeciesSection.

Để thêm cá, thêm một đối tượng mới vào frontend/src/data/fish.js và đặt id duy nhất. group phải là tropical hoặc coldwater; level phải khớp với các giá trị trong lựa chọn bộ lọc. Thêm nguồn để người đọc kiểm tra thông tin.

Khi người dùng mở hồ sơ, App.jsx thêm mã loài vào URL, ví dụ ?fish=betta, rồi hiển thị FishDetailPage. Người dùng có thể tải lại hoặc chia sẻ URL đó. Sự kiện Back của trình duyệt cũng đọc URL và đưa giao diện về đúng trang.

GIAO DIỆN VÀ RESPONSIVE

frontend/src/styles.css dùng className trong JSX để định dạng. Trong React, thuộc tính className tương đương thuộc tính class trong HTML.

Các biến màu trong :root như --ink, --green và --lime giữ màu dùng chung. Đổi giá trị biến để đổi màu ở nhiều khu vực cùng lúc.

@media (max-width: 720px) chứa các điều chỉnh cho điện thoại: menu chuyển thành menu mở/đóng, lưới cá thành một cột và các khu vực xếp theo chiều dọc.

Theme MUI xử lý kiểu mặc định cho component thư viện; CSS riêng xử lý bố cục thương hiệu. Tách hai phần này giúp tránh phải viết lại toàn bộ kiểu dáng của các component MUI.

CHẠY DỰ ÁN

Sau khi cài Node.js, mở Terminal tại thư mục dự án và chạy:

Terminal 1: cd backend npm start

Terminal 2: cd frontend npm install npm run dev

npm start khởi động API. npm install tải thư viện React được khai báo trong frontend/package.json. npm run dev khởi động Vite; mở địa chỉ localhost mà Terminal in ra để xem website. Vite chuyển tiếp yêu cầu /api đến cổng 3000.

Để chạy hai phần bằng Docker, mở Docker Desktop rồi từ thư mục gốc chạy:

docker compose up --build

Mở http://localhost:8080. Docker build frontend thành tệp tĩnh, Nginx phục vụ trang và chuyển tiếp /api/ tới backend. PostgreSQL tạo bảng users và lưu dữ liệu trong named volume aqua_atlas_db_data. Nhấn Ctrl+C để dừng; docker compose down xóa container và network nhưng giữ volume dữ liệu. Chỉ dùng docker compose down -v khi chủ ý xóa database local.

Để chỉ build frontend, chạy npm run build bên trong frontend/. Tệp đầu ra nằm trong frontend/dist/. node_modules/, dist/ và .env bị bỏ qua bởi Git.
